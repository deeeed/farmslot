# Explainer video scripts

The landing page should not only show screens. Each video should explain one product promise in a human voice:

> Farmslot is your **agentic engineering framework**: scale work across many projects, machines, and model runners, **watch and steer** agents while they work, then trust results through visual validation, executable recipes, and proof artifacts.

Use this page as the recording index. Each concept has its own script so the narration, shot list, captions, and success criteria can evolve independently.

## Voice and pacing

- Speak like a builder showing a real workflow, not like a spec writer.
- Say what problem the feature solves before naming the feature.
- Prefer verbs: dispatch, watch, steer, validate, review, improve.
- Show one complete idea per clip; avoid long dashboard tours.
- End each clip with the evidence or decision a human can act on.

## Product concept videos

## Recording checklist

Before publishing each video:

- verify the clip uses sanitized fixture data;
- extract and inspect a poster frame;
- add captions or nearby transcript text;
- keep the title focused on the product promise;
- confirm the clip shows a real product surface, not a static documentation mock;
- link the clip back to the relevant guide, protocol, or product page.
