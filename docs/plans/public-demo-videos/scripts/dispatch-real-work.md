# Dispatch real work

## Product promise

Start an agent with the right repo, branch, slot, task, environment, and validation path instead of dropping a prompt into a blank chat.

## Narration script

> Instead of pasting a prompt into a blank chat, I dispatch the task into a prepared engineering slot. Farmslot already knows the project, branch, device, ports, hooks, and validation path. The agent starts from the same kind of environment an engineer would use, so the work begins with context instead of guesswork.

## Shot list

1. Open Command Center on a sanitized task or demo issue.
2. Show the selected project, slot, and worker runner.
3. Start the run.
4. End on the run page with the agent connected and terminal output beginning.

## On-screen captions

- “Dispatch into a prepared workspace.”
- “Project, slot, device, hooks, and validation are already attached.”
- “The agent starts with engineering context, not a blank prompt.”

## Success criteria

The viewer understands that Farmslot turns “ask an agent” into “assign work to a controlled engineering workspace.”
