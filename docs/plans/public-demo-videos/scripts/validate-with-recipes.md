# Validate with recipes

## Product promise

Turn acceptance criteria into executable setup, real actions, visual validation, mechanical assertions, screenshots, traces, summaries, and pass/fail evidence.

## Narration script

> A final agent summary is not enough. Recipes make validation visible and executable. They set up the state, perform real actions, assert the result, capture screenshots or traces, and produce a reviewable summary. That gives me proof instead of vibes.

## Shot list

1. Show a recipe graph or recipe run.
2. Highlight setup, action, assertion, and teardown nodes.
3. Show generated screenshots, traces, or summary artifacts.
4. End with a clear pass/fail state that a reviewer can inspect.

## On-screen captions

- “Acceptance criteria become executable proof.”
- “Setup → action → assertion → evidence.”
- “Review artifacts, not claims.”

## Success criteria

The viewer understands that recipes are the core trust concept: they make the agent prove the work visually or mechanically before the human trusts it.
