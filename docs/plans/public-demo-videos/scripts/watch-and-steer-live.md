# Watch and steer live

## Product promise

Keep the human in the loop during execution: inspect live state, approve decisions, redirect the agent, or stop the run before it drifts.

## Narration script

> The important part is not just watching an agent. I can steer it while it works. I see the terminal, app state, logs, artifacts, and current plan. If the agent needs a decision, or starts going in the wrong direction, I can approve, redirect, or stop the run before it wastes hours.

## Shot list

1. Show a live Command Center run timeline.
2. Open terminal output or worker activity.
3. Show a decision gate or review checkpoint.
4. Approve, redirect, or annotate the run.
5. End with the run continuing under human control.

## On-screen captions

- “Watch the work while it happens.”
- “Steer before the agent drifts.”
- “Human approval remains part of the loop.”

## Success criteria

The viewer understands that Farmslot is active supervision, not a passive dashboard and not fully autonomous blind execution.
