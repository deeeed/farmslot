# Cross-review before merge

## Product promise

Use independent model review plus human judgment so one agent does not self-approve its own work.

## Narration script

> One agent can build the change, but another should challenge it. Farmslot makes independent review loops part of the workflow. A reviewer checks the diff and the evidence, the worker fixes findings, and the human decides when it is safe to merge.

## Shot list

1. Show a completed worker change or PR-ready run.
2. Start or display an independent review pass.
3. Show a concrete finding and follow-up fix.
4. End with review approval and green validation.

## On-screen captions

- “Worker builds.”
- “Reviewer challenges.”
- “Human decides.”

## Success criteria

The viewer understands that Farmslot is designed for supervised confidence, not self-approved automation.
