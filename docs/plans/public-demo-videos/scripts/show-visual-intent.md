# Show visual intent

## Product promise

For UI projects, the agent communicates its current intent inside the app while recording proof from real user-like interactions.

## Narration script

> For UI work, the agent should explain what it is doing to the human watching the app. The HUD stays small, shows the current intent, and updates as flows compose. The recording then proves the real app interaction, not a hidden state injection.

## Shot list

1. Open a sanitized UI app running a recipe.
2. Show the HUD with one short, human-readable intent.
3. Drive a real tap, input, scroll, or assertion.
4. Capture the visual proof artifact.

## On-screen captions

- “The app explains the current intent.”
- “Small HUD, high signal.”
- “Proof comes from real UI interaction.”

## Success criteria

The viewer understands why Farmslot treats visual intent and proof as first-class parts of UI validation.
