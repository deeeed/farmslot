# Framework for many project types

## Product promise

Use one agentic engineering framework across very different projects: mobile apps, web apps, browser extensions, desktop apps, CLIs, services, workers, and headless systems.

## Narration script

> Farmslot is not built for one repository shape. The same loop can work for a React Native app, a web app, a backend service, a CLI, a browser extension, or a headless worker. Each project brings its own hooks and capabilities, but the operating model stays the same: dispatch, watch, steer, validate, review, and improve.

## Shot list

1. Show the project list or project-type onboarding docs.
2. Highlight a UI/mobile project with recipe HUD or visual evidence.
3. Highlight a headless or CLI project with logs and summary evidence.
4. End on the shared recipe proof layer and gateway contract.

## On-screen captions

- “One loop across many project types.”
- “Projects provide hooks and capabilities.”
- “Farmslot keeps dispatch, evidence, and review consistent.”

## Success criteria

The viewer understands Farmslot as a portable framework, not a one-off harness for a single app.
