# Learn from every run

## Product promise

Turn failures, flakes, and repeated review comments into durable improvements to prompts, docs, checks, recipes, and project adapters.

## Narration script

> The best part is the recursive loop. When a run fails, flakes, or reveals a better instruction, that learning should not disappear in chat history. Farmslot retrospectives curate durable lessons into docs, prompts, recipes, checks, and adapters so the next run starts stronger.

## Shot list

1. Show a failed, blocked, or reviewed run.
2. Show retrospective notes or curated learning.
3. Show the learning becoming an updated recipe, check, doc, or adapter.
4. End on the improved next-run path.

## On-screen captions

- “Failures become reusable lessons.”
- “Curate what should survive the run.”
- “Improve the system before the next dispatch.”

## Success criteria

The viewer understands that Farmslot compounds over time because each run can improve the operating system around the agents.
