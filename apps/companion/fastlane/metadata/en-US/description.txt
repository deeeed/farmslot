Farmslot is a mobile operator console for supervised agentic engineering.

Connect to your Farmslot gateway and keep a live view of slots, workers, recipe runs, decisions, pull requests, terminal sessions, and evidence artifacts from your phone or tablet.

Use Farmslot to:

• Monitor active agent slots and run health
• Review recipe evidence, artifacts, diffs, and decisions
• Follow pull requests and validation status
• Open worker terminals when you need to steer a task
• Switch between local, remote, and paired gateway profiles
• Draft instructions with optional on-device voice workflows
• Receive local notifications for important run and decision events

Farmslot is designed for developers who run multiple coding agents in parallel and need a compact, observable control surface while staying compatible with local-first workflows.
