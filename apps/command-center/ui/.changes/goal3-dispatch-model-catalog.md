- The Dispatch model picker loads Pi and OpenCode models without "Show model catalog", from the offline cache first. Models are grouped by provider (Consensys LiteLLM, xAI, Anthropic, Local), a model only some nodes have says which ("macpro only"), and "Loading models…" holds the row until the catalog arrives. The native session picker lists the models of the node the session will run on, and Dispatch candidate rows on a node without the chosen Pi or OpenCode model show as ineligible.
