- Tmux workers now run agent-browser in a session named after their slot (`AGENT_BROWSER_SESSION`). Terminal slot cleanup, after the run's workers are stopped, stops a detached agent-browser daemon of that session, or of any named session other than `default` started in the slot checkout; the session is read from the `<session>.sock` socket it listens on. A `default` daemon may serve workers on other slots: no cleanup rule stops it, and terminal cleanup logs it.
