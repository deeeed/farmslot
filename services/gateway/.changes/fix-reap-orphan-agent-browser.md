- Tmux runner launches and session reloads now run agent-browser in a session named after their slot (`AGENT_BROWSER_SESSION`). Terminal slot teardown, after the run's workers are verified stopped, stops a detached agent-browser daemon of that session, or of any named session other than `default` started in the slot checkout; the session is read from the one `<session>.sock` socket it listens on. No other cleanup rule stops an agent-browser daemon, and a `default` daemon, which workers on other slots may share, is logged and kept.
