- A fleet whose snapshot is past the freshness threshold or has no `checked_at` is now served stale, with no slot dispatchable, to the clients that read it through the shared cache and entity sync. They learn each change, including a status file that can no longer be read, without a reload. The fleet monitor refreshes the snapshot at half the threshold, so a fleet whose machines answer never turns stale, and every stale read starts a refresh.
