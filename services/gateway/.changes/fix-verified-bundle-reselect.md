- A slot whose node support selection moved to another bundle no longer runs farm commands from the bundle it selected before. The gateway caches a verified bundle per slot for 10 minutes, while the node may prune a bundle as soon as no slot selects it. When the local bundle returned to an earlier hash inside that window, commands were pointed at a deleted directory. On mini-ff-1 that made the dev-server shutdown fail, which left the sandbox gateway on its port, and the next dispatch failed with "port 8801 is already in use". A cached selected bundle now counts only while it is the slot's latest selection in this gateway, whether a command or prepare moved it. That covers a delivery that finishes after a newer one. A selection made by another gateway on the same node is not seen.
