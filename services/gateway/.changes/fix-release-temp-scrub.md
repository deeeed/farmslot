- A new run's prepare clears the slot's `temp/` for the `temp/tasks` layout: everything goes except `temp/farmslot`, the runtime dir, the recipe harness, the watched resource dirs and the task dirs of the run, its parent chain and runs still bound to the slot (a queued `--slot` pin or a run parked off the slot does not stop it). Each removed task dir is named with its run and bundle status. A nested Git checkout is saved as parked refs in the slot repo (`refs/farmslot/parked/`), confirmed, then deleted, its worktree admin pruned; one that cannot be parked fails prepare by name. Release now deletes `scratch*` dirs instead of parking them under `<farm home>/parked-scratch`, where a later trial could read them; scratch holding a checkout is left for prepare.
