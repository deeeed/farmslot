- Prepare for a new run clears the slot's temp/ (temp/tasks layout) except farm state (the runtime dir and the project's watched resource dirs), the run's own and its parent chain's task dirs. Nested Git checkouts are moved out of the checkout, never deleted. Anything else that stays fails prepare by name, as does another live run on the slot. Release drops only its own task dir, once its bundle holds every file in it.
