- A new run's prepare clears the slot's `temp/` for the `temp/tasks` layout. It keeps `temp/farmslot`, the runtime dir, the recipe harness, the watched resource dirs, and the task dirs of the run, its parent chain and runs still bound to the slot. A queued `--slot` pin or a run parked off the slot does not stop it; another live run does, by name.
- Each removed task dir is named with its run and bundle status. A nested Git checkout is deleted outright and named with its kind: a worktree its repository lists at that path through `git worktree remove --force --force` (its branch is kept), any other checkout as a dir. A checkout holding a kept path, or a repository with a worktree outside `temp/`, is refused.
- Release clears worker `scratch*` dirs (directly under the task root, a flow folder, or `temp/` for the `temp/tasks` layout) before the age prune. The `temp/tasks` layout deletes them and refuses scratch holding a checkout, which prepare then deletes; other task roots park them by atomic rename under `<farm home>/parked-scratch/<slot>/<time>/`, the farm home resolved as blind trials resolve it, refusing a move across devices. A dir holding `TASK.md` is never touched.
