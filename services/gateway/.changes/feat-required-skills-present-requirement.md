- A prepare profile can require `required_skills_present`, so a profile that skips the `deps` phase falls back to one that runs it when a skill the pack's `required_skills` names is missing from the checkout. Release clears the farm-owned paths that hold installed skills and `deps` restores them, so an `attach` dispatch could otherwise reach task init with the skill gone and be refused before dispatch ("Refresh the slot skills, then prepare again.").
