- Prepare, replays included, starts a run's existing work branch from the current base when the branch has no commits of its own. Before, a replay reused such a branch at its old base, so a base-side fix (for example a re-sorted manifest the tracked-file check needs) kept failing every replay until the branch was moved by hand. Branches with their own commits, and runs with an explicit start ref or stack base, keep their base.
