- Fleet status keeps a slot's branch and commit while its node support bundle is still being delivered. A health or device hook that calls a farm script now runs in its own probe batch, so a pending bundle no longer blanks the git, worktree and default-branch probes and shows a `main` checkout as branch `-`. A bundle delivery that finishes after every waiter's budget ran out is now remembered, so the next command uses it instead of starting a fresh delivery that never catches up.
