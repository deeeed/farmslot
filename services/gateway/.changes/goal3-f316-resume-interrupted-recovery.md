- A gateway restart in the middle of a slot release no longer leaves the slot held until someone retries by hand. On startup the interrupted recovery is still turned into a hold first, then run once more from fresh workspace evidence. That re-run refuses unverified or local work, as an automatic release does, so it never advertises an unverified checkout. A recovery that fails again stays held for the operator. Before, the ae4598a4 deploy restart caught 2df8ce8a's release of macpro-audiolab-4 at its git step, and the slot stayed "Workspace recovery interrupted; retry Release and update to main" until `slot refresh --recover` (F316).
