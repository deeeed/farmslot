- Publication validates the task-action references of the selected recipe attempt only, so a run whose superseded attempts ran against an earlier task-action library no longer refuses with `library digest does not match the recorded recipe: expected <current>, <stale>, found <current>`. Retained attempts stay retained; an attempt that records two library digests for its own actions is still refused. The frozen publication verifier draws the same line: the selected attempt's claim is the digest anchor for the retained library, and a superseded attempt carried as additional evidence has its inputs checked for presence instead of being folded into one digest expectation — so a before/after pair recorded across a library move publishes, while missing or corrupt implementations still refuse.
