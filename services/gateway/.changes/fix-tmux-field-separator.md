- tmux queries no longer separate `-F` fields with a tab: tmux 3.4 escapes control characters in format output, so every tab-separated row arrived as one field there and pane, window and session reads silently found nothing (a restore reported "has no panes" for a window that had one). All formats and their parsers now use one printable separator, a row whose field count is wrong is rejected rather than read loosely, and a restore that drops rows says whether they were unparsable, from another session, or the devserver log.
