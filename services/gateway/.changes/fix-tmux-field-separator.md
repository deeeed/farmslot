- tmux queries no longer separate `-F` fields with a tab or a bare `|`: tmux 3.4 escapes control characters in format output, so every tab-separated row arrived there as one field and pane, window and session reads silently found nothing. A restore reported "has no panes" for a window that had one, and slot teardown, idle dev-server reclaim, owned-stop and worker adoption were all blind on Ubuntu.
- Every format and its parser now use one printable multi-character separator, a row whose field count is wrong is rejected rather than read loosely, and a restore that drops rows says whether they were unparsable, from another session, or the devserver log.
