- A run on an existing PR branch (pr-complete, or dev on a published branch) can start when that branch's lockfile drifted from package.json: prepare exports `FARMSLOT_PREPARE_LOCKFILE_DRIFT=allow` to the deps hook and accepts a deps phase that rewrites only lockfiles, logging that the worker must commit them. Otherwise a drift failure fails with `failureKind: 'lockfile-drift'` and a message naming the package.
