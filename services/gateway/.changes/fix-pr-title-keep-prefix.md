- A published PR title keeps a ticket title that is already a conventional subject, using the same subject check as CI and judging it before platform-prefix and trailing-period cleanup. A dev run no longer turns `chore(scope): ...` or `ci: ...` into a second prefix. A title that is not itself conventional still gets the flow type, including one whose platform tag hid a conventional subject. The lightweight completion title writer uses the same check, and still appends a configured title suffix. A leading `[BUG]` or `[FEATURE]` tag is dropped before that prefix, including a following colon, dash, or hyphen. `[Bug]: Ledger: unable to swap` becomes `fix: ledger: unable to swap`. A tag with nothing after it publishes no title.
