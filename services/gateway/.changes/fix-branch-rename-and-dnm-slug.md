- Push verification reports a renamed or switched run branch instead of failing with a git error (F327). When HEAD is not on the run branch, the completion check records whether the branch still exists and where HEAD is, never passes, and tells the worker how to put the work back: rename the branch back, check the run branch out, or recreate it at its commit, then push or commit. Before, a worker that ran `git branch -m` to add DO NOT MERGE to the name crashed verification with `rev-list` exit 128.
- A ticket or PR title marked DO NOT MERGE (in capitals, joined, bracketed, closing the title, or as `[DNM]`; a sentence such as "Do not merge duplicate rows" isn't a marker) keeps the marker in its generated branch slug, as a leading `do-not-merge` segment that truncation cannot drop, for every project (F327: run 9819c7bf's slug lost it).
