- When release cannot return a finished artifact-only run's checkout to idle (a stale working row, a node closeout not yet confirmed), the slot no longer stays on the run branch until someone refreshes it. Reconcile retries the same fenced idle return, with back-off, once the slot is ready, unowned, still on the run's released head with a clean tree (checked again when recovery inspects it), its node has stayed connected, and the run's bundle holds its task. The run's commits are parked before the reset. A run that meets a workspace recovery on its slot waits or selects again instead of failing, and any successful idle return clears the run's "Checkout retained" note.
