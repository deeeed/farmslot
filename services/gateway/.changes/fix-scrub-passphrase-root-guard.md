- Credential redaction catches quoted passphrases with spaces under `_SECRET`/`_PASSWORD`/`_PASSWD` names, in commands and env maps; `_KEY`/`_TOKEN` values with spaces are still left alone.
- `scripts/scrub-run-credentials.mts` refuses a `--root` that resolves (following symlinks) to `/`, the home directory, the farm home or a directory containing it, a system tree (`/System`, `/Applications`, `/Library`, `/usr`, `/bin`, `/sbin`, `/opt/homebrew`) or a path with fewer than 3 segments outside the temp dir, and exits with status 2 before scanning.
- With `FARMSLOT_SCRUB_ALLOWED_PREFIX` set, the scrub script and library refuse any root, and any file write, whose real path is outside that directory. The scrub tests set it to their own temp dir and fail if a scrub root resolves anywhere else.
