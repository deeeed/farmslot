- Settled runs not on an open PR keep their storage 7 days instead of 48 hours, set by `runBundleRetention.runRetentionDays` in `run-bundle-retention.json`. Every run on an open PR, or one whose PR state could not be read, stays held, and a run family shares that state with members that never recorded the PR. A recorded close settles a run only after a complete open-PR read. An unsettled follow-up or review also holds the runs it still reads, rechecked just before each run moves.
