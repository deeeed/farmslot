- Settled runs keep their storage 7 days instead of 48 hours, set by `runBundleRetention.runRetentionDays` in `run-bundle-retention.json`. Past that age an open PR, or one whose state could not be read, holds only the runs its warm review chains continue from, and an unsettled follow-up holds the run family it inherits from; other runs on the PR follow the age rule.
