- Settled runs not on an open PR keep their storage 7 days instead of 48 hours, set by `runBundleRetention.runRetentionDays` in `run-bundle-retention.json`; every run on an open PR, or one whose PR state could not be read, stays held. An unsettled follow-up or review also holds the runs it still reads, rechecked just before each run moves, and a reopened PR counts as open even when a run recorded it closed.
