- Settled runs keep their storage 7 days instead of 48 hours, set by `runBundleRetention.runRetentionDays` in `run-bundle-retention.json`. Past that age an open PR, or one whose state could not be read, holds only the review runs a warm review could continue from, and an unsettled follow-up or review holds the runs it still reads, rechecked just before each run moves; other runs on the PR follow the age rule.
