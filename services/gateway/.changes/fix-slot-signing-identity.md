- `git-identity.json` accepts a `"projects": {"<projectId>": {<git config keys>}}` map over the farm defaults, so prepare, signing checks and publication use the slot project's identity. Prepare writes a matching `gpg.format` with every signing key, inferring `ssh` for `ssh-`/`key::` literals or `.pub` paths and `openpgp` otherwise; contradictory formats fail at load, and signing failures give format-specific fixes.
