- Prepare's deps, preflight, health and unlock hooks now see `FARMSLOT_FLOW_TYPE` beside `FARMSLOT_PREPARE_PROFILE`, so a pack can set up a runtime for a dev run without doing it for a review. A flowless prepare unsets it. The profile requirement probes (`dev_server_up`, `artifact_available`, `health_ok`) now run under the prepare's effective domain instead of the slot's default one.
