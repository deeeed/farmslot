- Run retention no longer keeps a run's storage on the gateway's disk because the run has any tag. Archiving is a move with a restore manifest, not a delete, so only the explicit `keep` tag holds storage in place. Before, any tag (unsteered, perps, release, …) pinned it, and the retention dry run held 222 runs as "operator-tagged", more than any other reason (ADR-039 Amendment 3).
