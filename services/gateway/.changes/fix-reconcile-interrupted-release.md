- A cancel whose slot cleanup a gateway restart interrupted is now finished by reconcile, instead of leaving the slot busy and releasing until someone runs an owner-bound release. The cancel's fence carries what it settles on (the replay hold, or a released slot), so the restarted gateway finishes it once the node is back and the checkout checks clean; a finish that fails settles the same visible hold the cancel would. A cancelled run's interrupted cleanup hold is retried the same way as a finished run's.
