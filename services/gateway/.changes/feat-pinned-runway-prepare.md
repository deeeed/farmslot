- A comparison dev or fix-bug run with a `startRef` on a project that declares `artifact_check` or `prepare.pinned_profiles` now prepares a build of its start commit or fails before its worker starts. Prepare selects strictly from `pinned_profiles`, passes the resolved commit to preflight as `FARMSLOT_PREPARE_BASE_SHA` and requires the preflight's `prepare-artifact.json` receipt; a refusal's reason is the prepare error. The installed build is recorded on `run.prepareArtifact` (returned by `run.get` and copied to the run episode); dispatch, restart recovery and `skipPrepare` refuse a pinned run without it, and a replay that would re-dispatch restarts from prepare. Capsule and proof trials record the Runway build their slot reports, unenforced, so analysis can filter mismatched cells.
