- Prepare no longer fails a run because a node support bundle is still being delivered after 10 s. It waits for the delivery to finish or fail, bounded by the delivery's own deadline (5 minutes from its start). A re-delivery after a node redeploy re-verifies every file and used to lose to the fixed wait seconds before it finished (run 1a533f86). A wait that ends early now names the bundle, the phase it was in and the bytes left to send. The upload goes in 4 MiB requests so the bytes left are known. A delivery past its deadline no longer holds the slot: the next command starts a new one.
