- A fresh Claude review defaults to medium on both managed workspace transports and in the pipeline reviewer. A warm retry, recovery, or re-review keeps the effort recorded on that session, including an unset pre-upgrade launch, and the published review row stores that same effort. Cold recovery reads the admitted context instead of filling medium. An explicit plan row does not match a review recorded with no effort. An omitted row still does. A cold Claude plan row stays omitted through the pipeline and the publication gate, so recovery can read the admitted effort. A continued terminal review stores that recorded effort on the resumed session and on the reviewer context the next resume reads. An expired warm review carries the retained reviewer's effort into its cold fallback when the request omitted one, so the choice the queue records no longer drops to the runner's default; an explicit cold launch keeps the effort it asked for. Admission can still refuse that recorded cold choice against a saved warm policy as `Reviewer configuration changed`, which is a pre-existing hold and not addressed here. The resolved resume effort is stored with the pre-delivery marker, and a restart that adopts that worker keeps it. A stopped Claude review can be retried with an explicit effort matching the one it inherited. Claude workers keep an omitted effort unset. Native chat does not advertise medium for that omission.
