- Run transitions on two slots of one machine no longer wait for each other. Each run action (cancel, archive, slot reconcile, package preparation) shares its machine's transition key and takes its own run's key; only a machine pause or restore takes the machine key alone, after the run actions already in flight, and later run actions wait for it. Before, every run action held `machine:<node>` for its whole length: c07ce071's cancel on macpro-audiolab-2 waited 482 s behind another run's publish package refresh, and its archive waited 181 s behind that cancel, which is the 360 s run-bound teardown hang behind F313 (F314).
