- A gateway restart during DISPATCH no longer stops and relaunches a tmux worker that already has its task. Dispatch now records when it starts handing the task over (`promptDeliveryStartedAt`, on disk before the launch or send) and marks the slot working once delivery is verified. On restart, a worker that holds its task is adopted and the run resumes at MONITOR with the worker untouched; a delivery that can't be established takes the existing prompt-delivery-uncertain hold with the worker and slot preserved; a dispatch that never sent a prompt runs again.
