- Slot release moves worker scratch out of the task root, never deleting it. Scratch here means directories under `temp/tasks` that hold files but are no run's task dir, such as `temp/tasks/scratch-probe`. They go to `.agent/parked-scratch/<time>/`, and the release log names where. Before, they survived release, and the next blind dataset run's preflight refused the slot or saw them. A slot with an active task is left alone.
