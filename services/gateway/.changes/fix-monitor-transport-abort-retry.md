- A turn that ended because the runner's model connection dropped no longer fails the monitor or the review: they keep watching the live worker or reviewer. Pi's hook marks such turns `failureKind: 'transport'`; any other runner-reported failure, such as an expired login, blocks the monitor on a runner-unavailable decision with the worker kept. Its Continue watches on, and its Abort Run cancels the run (F328).
- A failing run no longer tears down an agent without evidence that it finished or is gone (a terminal signal file, or its process or pane missing). Without it, the run is blocked on a "worker left running" card whose Replay step resumes the step and whose Cancel run stops the agents; a gateway restart re-enters a parked monitor. A monitor that loses its node connection watches again, up to three times (F328).
