- A run's `taskNote` reaches task init as its own `operatorNote` field instead of being folded into `taskDocumentAdditions`, so the renderer can place it ahead of the task and give it a checklist step. A node older than agent-runtime 0.51.0 ignores that field and would drop the note entirely, so a slot on such a node keeps the old end-of-document `## Note` section until it is redeployed; an unreported node runtime counts as old.
