- A CI-watch or re-review chained run no longer fails its warm handoff with "Slot … is mid-release; warm handoff cannot claim it" when its parent's cleanup ran while the chained run was already active. The parent's cleanup leaves the slot held for that run ("Another active run … uses this slot"); the chained run may now claim exactly that hold, from find-slot, the warm handoff or its fresh-dispatch fallback, and the claim clears it. Task staging accepts the same hold, a fleet refresh no longer marks the chained run's lease lost on its parent's row, and a slot the run cannot claim is refused before the prompt reaches the worker.
