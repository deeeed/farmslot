- Heavy gateway writes stop at a free-space floor. Every slot-to-gateway copy (completion capture into the artifact mirror, `run.refreshMirror`, session archives, the release's scaffolding archive, review workspaces) and every run-bundle materialization refuses before writing when its volume has less free space than `FARMSLOT_HEAVY_WRITE_FLOOR_GB` (default 50). The error names the path, the free space and the floor. Gateway test processes default to no floor (Arthur, 11-02).
- A configured storage root on a missing volume is never recreated elsewhere. A write into a `FARMSLOT_RUNS_DIR` or `FARMSLOT_HOME` that is missing along with its parent is refused with "<name> <path> is missing and so is its parent (is its volume mounted?)", where `mkdir -p` would have rebuilt an unmounted volume's path on the internal disk. A configured root inside an existing parent is still created on first use. The run store creates a configured `FARMSLOT_RUNS_DIR` only that way, and the run-bundle store refuses to open such a missing `FARMSLOT_HOME` for writing.
