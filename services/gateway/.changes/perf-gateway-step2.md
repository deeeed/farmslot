- Local fleet slot checks and the pending-decision walk run in a `gateway-background` child process, off the request loop; local fixture hashes are read in-process and reused while a file keeps its size, mtime and inode. If the child is down, fleet refreshes fail (the fleet stays stale) and gateway.doctor's "Background process" check says so; `FARMSLOT_GATEWAY_BACKGROUND=0` runs these probes in-process instead.
- On local slots, fleet refresh, the branch watcher and the gateway update check read HEAD, refs, `.git` files and config from the checkout's files instead of spawning git, with the same answers git gives; anything outside the covered layouts (reftable, config includes, symref chains, another owner, unreadable files) still runs git. Status, diff, ancestry and abbreviated hashes stay git processes.
- Publication secret scanning runs on a worker thread, so a large log no longer holds the gateway for seconds. Publication waits for the completed scan, and refuses when the scan fails or is stopped, or when 32 scans are already waiting.
