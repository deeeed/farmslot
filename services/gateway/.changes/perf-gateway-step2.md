- GitHub reads and writes run in the gateway process over HTTP instead of one `gh` process per request. Callers keep the `gh` argument grammar (verified byte for byte against gh 2.98 output), keyring tokens are read once per host and account and re-read after a 401, and GET responses revalidate their ETags so unchanged data costs a 304 instead of rate limit. `FARMSLOT_GITHUB_API_URL` points every GitHub host at one origin for fixtures and proofs.
