- GitHub reads and writes run in the gateway process over HTTP instead of one `gh` process per request. Keyring tokens are read once per host and account and re-read after a 401, GET responses revalidate their ETags so unchanged data costs a 304 instead of rate limit, and `FARMSLOT_GITHUB_API_URL` points every GitHub host at one origin for fixtures and proofs.
- Internal callers migrate from the `gh`-argument grammar to named typed service methods (`github.rest`, `github.graphql`, `github.prView`, `github.prListFields`, etc.); a single consolidated GraphQL query replaces the six parallel `gh` calls for PR raw snapshot data, cutting per-snapshot GitHub API cost by up to 5×.
