- Prepare no longer strands unpushed commits when a new run reuses a work branch name. Release keeps a branch with unpushed commits for the next run of the ticket, but prepare then recreated it from base or reset it to origin or the start ref, leaving those commits only in a parked ref that retention prunes after 14 days. Before deleting or resetting the branch, prepare now keeps those commits on `<branch>-kept-<sha12>` and logs it.
