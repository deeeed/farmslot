- A slot resource boot or teardown no longer holds the capability registry lock while it runs. Each slot's runtime controls queue behind each other and other slots' run in parallel; a device control still refuses other slots that target its device on the same machine, naming the slot that is starting or stopping it. A teardown waits at most 30 s for a timed-out shutdown hook to settle, then reports the resource unconfirmed and holds the slot, and a dispatch waiting on a boot names it on its step. Before, mini-mme-3's stuck teardown froze every slot's capability acquires, boots and teardowns for 20+ minutes (F330).
