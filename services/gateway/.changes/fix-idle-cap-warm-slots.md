- The idle dev-server cap no longer exempts a keep-warm slot with no run forever: it keeps the server for 2 h instead of 15 min, then stops it. A keep-warm release on mini-mmt-3 had left the server and its prepare scope up for two days.
- When the cap stops a dev server on a slot with no owner, it also stops that slot's prepare scope, but only while the slot is ready with no live run, no other dev server is up and no capability lease holds it. The stop is fenced to the scope token read before the signals, under the same upkeep fence parked-work retention uses, and clears `warm`.
- Once per idle sweep, a prepare scope that outlived its dev server on such a slot (dev servers definitely stopped, no unrecorded worker pane) stops after the same window, 2 h when keep-warm. The window is kept on the slot row (`idle_prepare_scope`) so a restart does not reset it, and identity files are read once per machine per sweep; ghost, misconfigured and offline slots are skipped.
