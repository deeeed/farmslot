- A force-new-branch prepare without a linked worktree walks the worktree four times instead of six: the checkout of the default branch and its reset to origin become one `git checkout -B`, and the second checkout of the default, `branch -D` and `checkout -b` become one `checkout -B` that also drops the old branch config. Every refusal point (reset, clean, the default-branch porcelain check) is unchanged. Whether origin has the work branch is read from its fetch instead of a separate `ls-remote`.
