# Pending-decision recommendation pilot

Approved scope: [issue #719](https://github.com/deeeed/farmslot/issues/719). These 6 synthetic collision cases and their separate reference labels were written before any model calls. Review both files for validity before freezing their hashes and sending the case inputs. Never include `labels.v1.json`, its filename, or rationales in a model request. Synthetic task facts in this fixture are invented; a real `manual` ticket is not synthetic by default.

The fixed baseline is a pending gateway gate with the same visible action descriptions and no recommendation. The current profile gate has only two actions and cannot enter this pilot until #720 supplies two non-decline alternatives and a new frozen dataset. Collision cases reproduce the current engine descriptions and action text. Those packets contain no operator intent, prior-run safety evidence, or worktree state, so all six collision references require abstention. The gateway retains the operator choice. These cases do not establish that a model will help on real tasks.

Before live calls, record source approval for the exact input digest, a verified provider/model price snapshot and a batch cap at or below 24 calls and USD 0.10. Capture each attempt, all unknown charges, model identity, latency, usage and cost; no retry or fallback. Report correct abstentions on the six collision cases with the denominator visible. There is no measurable choice-quality claim in this cohort. A provider response is valid only if it matches an action ID or the allowed abstention token. Freeze cases, labels and protocol before candidate calls; any edit creates a new version.

To test workflow impact, pair operator decisions made with and without advice on matched cases. Record the chosen action, independently adjudicated quality, total elapsed time and total model tokens/cost including the advisory call. Counterbalance order and show every exclusion. Until paired observations exist at equal quality, report workflow efficiency as **unknown**, even if synthetic classification accuracy is high.
