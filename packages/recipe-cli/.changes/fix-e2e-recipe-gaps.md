- `call` refuses several `key=value` inputs quoted into one argument (such as `"provider=hyperliquid network=testnet"`) when every later key is a parameter of the action, instead of reading them as one value (other text and JSON-quoted values stay one value), and validation help suggests the nearest parameter for an unknown input and the parameter whose values include a misplaced one (`Did you mean 'market_mode="pro"'?`); a suggested assignment keeps its value's type and is quoted for the shell. Help for a sensitive parameter, or one suggested for it, shows `<redacted>` and a `<value>` placeholder instead of the value.
- `call` prints the absolute path of each screenshot it wrote (`Screenshot:` lines, and `screenshots` in `--json`).
- `call` teaches a value of the wrong type with parameter help, for example `value expects a string; got number 2400. Quote it: 'value="2400"'`.
