- An installed CLI snapshot runs JavaScript built once at install, instead of transforming its TypeScript with esbuild on every call, and the most-called commands (`rpc`, `run`, `runs`, `slot`, `fleet`, `task`, `internal`) load only their own module. A polled RPC call drops from about 2.5 s to 0.7 s of CPU and from 233 MB to 110 MB. Checkouts and older snapshots still run from source; `FARMSLOT_CLI_FROM_SOURCE=1` forces it.
