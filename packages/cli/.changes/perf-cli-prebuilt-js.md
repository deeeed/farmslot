- On Node 24.11.1+, 25.1+ and 26+, an installed CLI snapshot runs JavaScript built once at install instead of transforming its TypeScript with esbuild on every call: a polled RPC call drops from about 2.5 s to 0.7 s of CPU and from 233 MB to 110 MB. Node 22 and earlier 24 releases run from source as before. On every Node, the most-called commands (`rpc`, `run`, `runs`, `slot`, `fleet`, `task`, `internal`) load only their own module. Checkouts still run from source; `FARMSLOT_CLI_FROM_SOURCE=1` forces it.
