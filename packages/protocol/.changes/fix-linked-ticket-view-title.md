- `runLinkedTicketsView` reports each ticket's `title` and whether the run `named` it — through its fetched key, a recorded linked ticket or an operator addition — so a caller can render the recorded summary and tell a real ticket from a ref that merely matches the Jira key shape. A backlog run's `MANUAL-000124` matches that shape, and treating it as a ticket publishes a dead browse URL. Recorded tickets keep the order the fetch recorded them in.
