- An iOS simulator recording that stops without writing its file now fails with "simctl recordVideo produced no file", the exit code or signal and the tail of simctl's stderr, instead of a bare ENOENT.
- On the bridge fallback path (apps without `__AGENTIC__.scrollIntoView`, such as MetaMask Mobile), `scroll-view --into-view` centres the target in its scroll container's visible frame, inverted and short lists included, instead of at the container's top edge under fixed headers; it returns the settled `targetRect` and fails when the target is still outside the frame.
- `scroll-view --into-view` on a target with no scroll container (a fixed bottom sheet) answers `ok` with `alreadyInView` and the target rect when the target shows whole in the window, instead of "No scrollable near testID".
