- An operator note (`--task-note`) is rendered as `## Operator note` under the task document's title, and inserted into the execution checklist as a step in front of the template's completion row. It used to be concatenated onto the end of the document: in run 1b7b8662 that put a repin instruction on line 945 of a 947-line TASK.md, and the worker — following CHECKLIST.md, which never mentioned the note — did everything else and not the repin. The step goes before the completion row, not after it: every farm template ends with its `mark complete --mark-last` row, and a step after that one leaves two boxes open so `--mark-last` refuses, then ticks the note step itself once the worker clears the first — recording the note as done without it being done. The rows that shift are renumbered in their labels too, so what the worker reads matches what `mark N` targets, and the freeze runs on the final checklist text, after the rewrite. `insertUnderTitle` places a section under the title for both the note and the mode preamble, skipping a leading frontmatter fence that a regex anchored at `^#` silently missed on lightweight interactive templates.
