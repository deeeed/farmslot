- An operator note (`--task-note`) is rendered as `## Operator note` ahead of the task block it overrides, and appended to the execution checklist as one final step the worker has to mark. It used to be concatenated onto the end of the document: in run 1b7b8662 that put a repin instruction on line 945 of a 947-line TASK.md, and the worker — following CHECKLIST.md, which never mentioned the note — did everything else and not the repin. The step is appended, never inserted, because `freezeChecklistDeclarations` freezes proof, deterministic and optional declarations by step number and templates carry their own `mark N` references, so every existing step keeps its number.
