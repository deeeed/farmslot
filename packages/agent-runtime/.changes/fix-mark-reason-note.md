- `./mark N --reason "<text>"` records that text as a `note` on the step's ledger event. The step stays done: only `--skip` waives it, and a skip's own `reason` is never overwritten, so a row skipped and later rechecked keeps why it was waived and gains what the recheck found. Before this the flag was accepted on a numbered step and silently discarded. `--reason` together with `--skip` is refused, an empty note is a usage error, and a re-mark replaces the note.
