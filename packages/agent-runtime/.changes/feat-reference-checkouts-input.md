- `task init` accepts `referenceCheckouts`: read-only checkouts of other codebases the task is compared against, already resolved by the caller. They are listed in the task document under `Reference checkouts (read-only)` with the revision to cite, and frozen in `inputs/reference-checkouts.json`. An absent one is recorded with `present: false` and named as absent in the document: a comparison nobody can read is blocked, and silence would read as unchecked.
